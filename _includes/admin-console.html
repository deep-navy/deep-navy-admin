GitHub Pages hands it to anyone who asks, so it documents nothing about how the platform is built: no internal endpoint paths, no table names, no workspace identifiers, no App-grant inventory, no cluster topology. Everything this console knows about deep.navy it learns from an authorized API response at runtime and renders into the empty containers below. test/admin_launch_surface_test.cjs is the guard that keeps it that way. Two structural rules, both forced by the page's own Content-Security-Policy: * no inline style attributes — style-src 'self' refuses them silently, so every visual decision is a class in assets/css/admin.css or the vendored design system; * no inline script — script-src 'self' with no hash allowance, and test/site_test.rb asserts the absence outright. Icons are one inline SVG sprite. The design system draws its icons from a CDN, which this CSP cannot reach; a sprite costs no request and no script. EVERY SHAPE IN THE SPRITE CARRIES pathLength="1", AND THAT IS LOAD-BEARING. The draw family (ds/components/core/icons-motion.css) animates stroke-dashoffset from the full path length down to zero, and it expresses that length as 1 — stroke-dasharray:1, stroke-dashoffset:1 -> 0. pathLength="1" is what makes 1 mean "the whole path": it tells the browser to scale every distance computation as if the path were one unit long. Without it, stroke-dasharray:1 is one user unit on a 24-unit grid, and the glyph renders as a crawling row of dots rather than a line drawing itself in. It fails as WRONG MOTION, not as no motion, which is why it gets a shout rather than a footnote. The design system does the same thing by rewriting each fetched SVG; a sprite has to author it. It is inert everywhere else: with no dash properties set, a pathLength changes nothing. So add it to any glyph added here, whatever family that glyph is expected to land in — icon-motion.js derives the family from the name, and the name can change. {%- endcomment -%} {%- comment -%} ============================ 1 · ACCESS ============================ {%- endcomment -%}
